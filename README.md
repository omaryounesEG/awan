## 🌙 بالعربية

### ما هو أَوَان؟

**أَوَان** تطبيق إسلامي متكامل للأندرويد، مبني على مبدأ واحد: **كل شيء يعمل على جهازك**.
لا خادم يرى صلاتك، ولا حساب يربط تلاوتك باسمك، ولا إعلان يقطع أذكارك. تفتح
التطبيق في الطائرة، في المسجد، في مكان بلا شبكة — وكل شيء يعمل.

> الإصدار الحالي **v1.27.0** صالح للاستخدام اليومي، والمزايا تُضاف وتُصقل باستمرار.

### المزايا

| | الميزة | التفصيل |
|---|---|---|
| 🕌 | **مواقيت الصلاة** | حساب فلكي على الجهاز من إحداثياتك، بلا إنترنت، مع عدّاد للصلاة القادمة وتقويم شهري |
| 🔔 | **الأذان** | أذان ١ وأذان ٢ وتنبيه ١–٣، وإشعار واحد فقط للصلاة القادمة يُستبدله كل أذان جديد ولا يتراكم |
| 🕌 | **تكبيرات العيد** | تلقائيًا قبل شروق يومَي الفطر والأضحى بخمس وعشرين دقيقة، بصوت التكبيرات — دون أي ضبط يدوي |
| 🤫 | **الصامت الذكي** | يصمت الهاتف وقت الصلاة والجمعة فقط، ومقيَّد بنطاق المسجد المسجَّل — ولا يرفع الصامت اليدوي أبدًا |
| 📿 | **الأذكار** | أذكار الصباح والمساء بالعربية والإنجليزية كواجب يومي: عدّاد لكل ذكر، نسبة إنجاز، تقرير شهري، تذكير، واستماع مع **وضع السيارة** |
| 📖 | **المصحف والتفسير** | نص عثماني بخطوط QPC حفص، تفسير ميسّر، تنقّل بالسور والأجزاء، وحفظ موضع القراءة |

| 🔬 | **أدوات الباحث** | قسم فرعي لمن يعمل بالحديث: بحث في المتون مع بيان الكتب التي روت المتن نفسه، وفهرس **٢٣٬٦٥٤ راويًا** بالدرجة وسنة الوفاة |
| 🧩 | **المتشابهات اللفظية** | رسم معرفي لـ **٨٦٥ آية** و**٢٬٨٠٣ وصلة** تشابه، مع طبقات للتشابه التام والتقارب |
| 🔎 | **البحث الدلالي** | بحث بالمعنى لا بالحرف، بمحرّك تضمين يعمل محليًا دون إنترنت |

### الخصوصية — بالتفصيل الذي يستحقه الأمر

- **لا حساب، لا تسجيل، لا بريد.** تفتح التطبيق وتستخدمه.
- **لا إعلانات ولا تحليلات ولا تتبّع** — لا Google Analytics، ولا Facebook SDK، ولا Firebase.
- **تسجيل التلاوة لا يُرفع ولا يُحفظ:** يُعالَج في الذاكرة على الجهاز ثم يُنسى.
- **الموقع يُقرأ على الجهاز** لحساب المواقيت والقبلة ونطاق المسجد، ولا يُرسَل إلى أي خادم.
- **لا يعمل في الخلفية بلا إذنك:** لا فحص دوري ولا خدمات خفية.
- **الشبكة تُستخدم عند طلبك فقط:** تنزيل محرك التلاوة، صوت الأذكار، كتب المكتبة، وفحص التحديث.
- **التحديث ذاتي ومباشر من GitHub** — بلا متجر ولا طرف ثالث، وبتحقّق SHA-256 قبل التثبيت.

### التحديث المصغّر (Delta Updates)

الـAPK على الهاتف من النسخة المثبَّتة، ثم يتحقّق من بصمة SHA-256 قبل تسليمه لمُثبِّت أندرويد:

## 🇬🇧 English

### What is Awan?

**Awan** is a complete Islamic app for Android built on one rule: **everything runs
on your device**. No server watching your prayers, no account tying your recitation to
your name, no ad between you and your adhkar. Open it on a plane, in a mosque, in a place
with no signal — and it works.

> Current release **v1.27.0** is usable daily; features are added and polished constantly.

### Features

| | Feature | Detail |
|---|---|---|
| 🕌 | **Prayer times** | On-device astronomical calculation from your coordinates, next-prayer countdown, monthly timetable |
| 🔔 | **Adhan** | Adhan 1, Adhan 2 and alerts 1–3; exactly one upcoming-prayer notification, replaced by the next adhan instead of stacking |
| 🕌 | **Eid takbir** | Automatically twenty-five minutes before sunrise on both Eids, using the takbir clip — no setup |
| 🤫 | **Smart silence** | Silences the phone only at prayer and Friday prayer, only inside the registered mosque fence — never overrides a manual silent |
| 📿 | **Adhkar** | Morning and evening remembrances in Arabic and English as a daily task: per-thikr counter, progress, monthly report, reminder, listening and a **car mode** |
| 📖 | **Qur'an & tafsir** | Uthmani text in QPC Hafs fonts, a concise tafsir, surah/juz navigation, saved reading position |
| 📜 | **Hadith** | **36,038 narrations** from seven books: Bukhari, Muslim, Abu Dawud, Tirmidhi, an-Nasa'i, Ibn Majah and Muwatta Malik — diacritics-insensitive search, filters by book/grade/chapter, and takhrij linking the same matn across books (2,759 links) |
| 🔬 | **Researcher tools** | A sub-section for people who work with hadith: matn search showing which books narrate the same matn, and an index of **23,654 narrators** with grade and death year |
| 🧩 | **Mutashabihat** | A knowledge graph of **865 verses** and **2,803** textual-similarity links, layered by exact and near similarity |
| 🔎 | **Semantic search** | Search the Qur'an by meaning with a local embedding model, offline |
| 🎙️ | **Recitation check** | Listens to your recitation and aligns it to the ayah word by word, **entirely on-device** — audio never leaves the phone |
| 📚 | **Library** | Islamic books downloaded once, then read offline with fast in-book search |
| 🧮 | **Al-Mi'dad** | A Qur'anic text-statistics lab: words, letters, frequencies, tied to a stated convention — no numerological claims |
| 🧭 | **Qibla & mosque radar** | A sensor-based qibla compass and a radar of nearby mosques without a commercial maps service |
| 🌗 | **Arabic & English** | Two complete RTL/LTR interfaces, dark mode and an **elderly mode** at 150% scale |
| 🔄 | **Self-update** | An in-app update check wired to GitHub Releases — no Firebase, no store, SHA-256 verified |

### Privacy, precisely

- **No account, no sign-up, no email.**
- **No ads, no analytics, no tracking** — no analytics SDK, no social SDK, no Firebase.
- **Recitation audio is never uploaded or stored:** processed in memory on-device and discarded.
- **Location is read on-device** for prayer times, qibla and the mosque fence; it is never sent anywhere.
- **No background work behind your back:** no periodic checks, no hidden services.
- **The network is used only when you press something:** engine download, adhkar audio, library books, update check.
- **Updates come directly from GitHub Releases** with SHA-256 verification before install.

### Delta updates

Instead of downloading 100 MB for every fix, the app downloads a small patch, rebuilds the
APK on the phone from the installed build, verifies its SHA-256, and only then hands it to
Android's installer. Measured: **8.5 MB** for v1.25.0, **7.1 MB** for v1.24.1, **0.6 MB**
for a routine release.

### Build

```bash
git clone https://github.com/omaryounesEG/awan.git
cd awan
flutter pub get
flutter build apk --release --split-per-abi
```

Flutter 3.x and JDK 17. To regenerate the hadith asset:

```bash
python tools/build_hadith_asset.py --source <hadith-json books dir> --out assets/hadith
```
